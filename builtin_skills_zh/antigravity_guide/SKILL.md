# Google Antigravity (AGY) 指南与参考地图

Google Antigravity 是一款 AI 原生研发平台。根据用户所询问的具体产品形态，你**必须**查阅本技能 `references/` 目录下的相应子文档：

## 1. 产品形态地图 (离线子文档)

-   **Antigravity CLI (`agy`)**：[references/cli.md](references/cli.md)
    -   包含斜杠命令、功能特性、设置项以及最佳实践的权威公开命令行文档索引。
-   **Antigravity IDE**：[references/ide.md](references/ide.md)
    -   涵盖独立 AI 优先 IDE、侧边栏聊天面板与内联代码透镜 (Code Lenses)。
-   **Antigravity 2.0**：[references/app.md](references/app.md)
    -   涵盖桌面端应用界面、左侧边栏、对话交互画布以及 HTML 辅助面板（子智能体、后台任务、工件 Artifacts、文件变更对比、集成终端）。
-   **Antigravity SDK**：[references/sdk.md](references/sdk.md)
    -   涵盖 Python SDK (https://github.com/google-antigravity/antigravity-sdk-python)，用于编程式智能体调度、编排 API 以及自定义工具暴露。
